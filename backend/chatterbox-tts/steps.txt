1- Run this command
-> py -3.11 -m venv venv
   .\venv\Scripts\Activate

2- Then Run this command
(venv) ..... -> pip install modal
(venv) ..... -> pip install -r chatterbox-tts\requirements.txt

3- Run the Modal setup command
(venv) ..... -> modal setup    // this command will generate an Auth token for your account
                               // You just need to click on Authorize button

4- -- Write the tts python file --

Finally:  depoly application by this command
(venv) ..... -> python -m modal deploy -m tts
